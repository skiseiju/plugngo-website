macOS 安全性設定教學

首次開啟 PlugnGO 時，macOS 可能會顯示安全性警告。這是正常的——依照以下步驟即可解除。

「無法打開」警告 「已損壞」錯誤 DMG 安裝方式 檔案存取權限 Sequoia 注意事項 疑難排解
為什麼會出現這個警告？
macOS Gatekeeper 會阻擋未在 Apple 公證（Notarization）的應用程式。PlugnGO 目前處於公測階段，尚未完成 Apple 公證流程，因此首次開啟時會被攔截。這不代表應用程式有安全疑慮——只是 macOS 的預設保護機制。

方法 C — 終端機指令（進階）
!

用終端機移除隔離屬性

如果以上方法都無效，可以用終端機手動移除 macOS 的隔離標記。開啟終端機（應用程式 → 工具程式 → 終端機），貼上以下指令：

# 如果安裝在「應用程式」資料夾：
$ xattr -cr /Applications/PlugnGO.app

# 或者 DMG 解壓後的位置：
$ xattr -cr ~/Downloads/PlugnGO.app

執行後再雙擊開啟 PlugnGO，就不會再出現 Gatekeeper 警告了。

設定完成！以後開啟 PlugnGO 都不會再被攔截。

macOS Sequoia（15.x）注意事項
!

Sequoia 收緊了 Gatekeeper 規則

如果你使用的是 macOS Sequoia（15.0 以上），Apple 進一步收緊了安全性限制：

右鍵「開啟」可能無效
Sequoia 對未簽署的 App 取消了右鍵開啟的捷徑。如果右鍵選單中按「開啟」後仍然被擋，請改用方法 A（系統設定 → 強制打開）。
系統設定方法仍然有效
到「系統設定 → 隱私權與安全性」點選「強制打開」，這在所有 macOS 版本都能使用。
終端機指令仍然有效
xattr -cr 指令在 Sequoia 上仍然可以正常使用。
如何確認你的 macOS 版本？
點選左上角 → 「關於這台 Mac」，就能看到版本號。
macOS 15.x = Sequoia ／ macOS 14.x = Sonoma ／ macOS 13.x = Ventura

還是無法開啟？

以下是常見問題的快速排查。

試了所有方法，還是顯示「無法打開」
  1. 確認已將 PlugnGO 從 DMG 拖到「應用程式」資料夾
  2. 開啟終端機，執行 xattr -cr /Applications/PlugnGO.app
  3. 到系統設定 → 隱私權與安全性，點選「強制打開」
  4. 如果以上都無效，嘗試重新下載 DMG 再安裝一次
PlugnGO 開啟後閃退 / 畫面空白
  1. 確認你下載的是正確的版本：M 系列 Mac 用 M系列版，Intel Mac 用 Intel 版
  2. 確認 macOS 版本在 12 (Monterey) 以上
  3. 嘗試刪除 PlugnGO 後重新安裝
  4. 如果問題持續，請到 公測頁面 回報問題
PlugnGO 偵測不到插入的記憶卡
  1. 確認記憶卡已在 Finder 中正常掛載（桌面或側邊欄可看到）
  2. 確認已授權「可卸除式卷宗」存取權限（系統設定 → 隱私權與安全性 → 檔案與資料夾 → PlugnGO）
  3. 如果是從 DMG 直接執行（未拖到應用程式），請先正確安裝再試
  4. 嘗試重新插卡，或換一個讀卡機
NAS 備份目標無法選取 / 寫入失敗
  1. 確認 NAS 已在 Finder 中連線並掛載
  2. 確認已授權「網路卷宗」存取權限（系統設定 → 隱私權與安全性 → 檔案與資料夾 → PlugnGO）
  3. 確認 NAS 上的共享資料夾有寫入權限
  4. 如果使用 SMB 連線，確認 Finder 中的掛載路徑是以 /Volumes/ 開頭
問題解決了？開始備份吧！
