macOS 首次開啟需要額外一個步驟，30 秒搞定。
首次開啟教學（點擊展開）
情況 A —「無法打開」警告
出現「Apple 無法檢查是否包含惡意軟體」的對話框
1
按下「完成」關閉對話框（不要按「移到垃圾桶」）。
2
打開 → 系統設定 → 隱私權與安全性，往下捲動找到「PlugnGO 已被阻擋」的訊息。
3
點選「強制打開」，輸入密碼確認。再次開啟 PlugnGO 即可正常使用。
情況 B —「已損壞」錯誤
出現「已損壞，無法打開，您應該將其移到垃圾桶」
1
按「取消」（不要按「移到垃圾桶」）。
2
開啟終端機（Spotlight 搜尋「終端機」），貼上以下指令並按 Enter：
xattr -cr /Applications/PlugnGO.app
3
再次開啟 PlugnGO，若仍出現「無法打開」，依情況 A 步驟操作即可。
注意事項
  • 請先將 PlugnGO 從 DMG 拖到「應用程式」資料夾，再開啟。直接從 DMG 執行可能導致功能異常。
  • 首次備份 SD 卡時，macOS 會詢問「可卸除式卷宗」存取權限，務必點「允許」。
  • macOS Sequoia (15.x) 使用者：右鍵開啟可能無效，請直接用「系統設定 → 強制打開」。
  • 只需設定一次，之後開啟都不會再被攔截。
